Employee Tracker

  ![License](https://img.shields.io/badge/-MIT-blue.svg)


## Description
    
    This app uses the terminal to track employees in a sql database, it will track the employees first and last name the role in the company, what department they are a part of and the salary they make you can also use the application to add employees, roles, or departments.

## Installation
    
    you will need to run npm install in the root folder, to install the dependices for this application. You will then need to run the schema.sql and seeds.sql in postgres to set up and seed the database  

## Usage
    
    In the terminal from the root folder navigate to the js folder then run node index.js, you will then be prompted with a list of actions you can us the arrow keys to navigate to which action you would like to do.
